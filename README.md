# Pixel Perfect – Classic Travel Connection

En React-applikation byggd med TypeScript, Vite och Tailwind CSS. Projektet är skapat som en "Pixel Perfect"-övning där målet är att efterlikna en vald webbsida från webbplatsen Classic Travel Connection.

## Tekniker

- React
- TypeScript
- Vite
- Tailwind CSS
- Git och GitHub

## Funktioner

- Header med logotyp och navigation
- Hero-sektion med stor bakgrundsbild
- Sociala ikoner
- Live chat-knapp
- Responsiv layout
- Styling med Tailwind CSS

## Komponenter

Projektet innehåller flera komponenter utöver `App.tsx`:

- `Header.tsx`
- `Hero.tsx`
- `SocialIcons.tsx`
- `LiveChatButton.tsx`

## Starta projektet

```bash
npm install
npm run dev
